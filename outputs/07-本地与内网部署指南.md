# 全国城市地铁可视化系统 — 部署指南（本地 / 内网）

**日期**：2026-08-14
**状态**：✅ 已就绪（静态站点 + 内网服务器）

---

## 一、一键启动

在项目根目录执行：

```bash
npm run start
```

该命令会先自动构建（`dist/`），然后启动静态服务器，并打印访问地址，例如：

```text
[serve-static] 静态站点已启动
  本机访问:  http://localhost:4173
  局域网访问: http://192.168.8.108:4173
```

> 只想启动、不重新构建时用 `npm run preview`；开发调试用 `npm run dev`（:5173，带热更新）。

## 二、访问方式

- 本机：http://localhost:4173
- 同一局域网内其他设备（手机/平板/电脑）：`http://<本机局域网IP>:4173`
  - 查看本机 IP：`ipconfig`（IPv4 地址），或直接看启动日志。
- 修改端口：`set PORT=8080 && npm run start`（Windows）或 `PORT=8080 npm run start`。

## 三、Windows 防火墙（局域网设备访问必做）

其他设备访问前，需要在“Windows 安全中心 → 防火墙和网络保护 → 高级设置”中
添加入站规则，放行 TCP 4173 端口（或选择“允许应用通过防火墙”放行 Node.js），否则会被防火墙拦截。

## 四、部署到其他服务器（可选）

`dist/` 是纯静态站点，可复制到任意环境：

- **Nginx**：`root /path/to/dist;`，并配置 SPA 回退：
  ```nginx
  location / {
      try_files $uri $uri/ /index.html;
  }
  ```
- **Apache**：`.htaccess` 中配置 `FallbackResource /index.html`；
- **任何静态托管平台**（GitHub Pages / Netlify / Vercel / Cloudflare Pages）：直接上传 `dist/`。

## 五、更新数据

```bash
python scripts/fetch_subway_data.py   # 抓取最新数据
python scripts/build_dataset.py       # 重新清洗
npm run start                         # 重新构建并发布
```

## 六、安全提示

- 当前为**无鉴权**的静态站点，适合本地演示与内网使用；
- 如需公网访问，建议部署到带 HTTPS 的托管平台，或通过反向代理 + 访问控制（如 Nginx + 密码/内网 VPN）保护。

## 七、GitHub Pages 公网部署（已准备）

应用已适配 GitHub Pages：

- 路由改为 **Hash 模式**（`/#/city/beijing`），任何静态托管零配置、刷新不 404；
- 提供 `build:pages` 构建脚本（资源路径自动加 `/china-metro-visualization/` 前缀）；
- 提供 `scripts/deploy-gh-pages.mjs` 一键部署脚本：创建仓库 → 推送源码 → 构建 → 发布 `gh-pages` 分支 → 启用 Pages → 等待构建完成。

运行方式：

```bash
set GH_TOKEN=<你的 GitHub Personal Access Token>
npm run deploy:pages
```

Token 要求：classic token，勾选 `repo` 权限（或 fine-grained：Contents 读写、Pages 读写、Administration 读写、Metadata 只读）。
仓库名默认 `china-metro-visualization`（public），可用环境变量 `GITHUB_REPO` 覆盖。
部署完成后访问 `https://<用户名>.github.io/china-metro-visualization/`。

> ⚠️ Token 仅在部署时使用，部署完成后建议立即在 GitHub 设置中撤销（Regenerate/Delete）。
